# Signal/Noise Founder Video Script (35 seconds)

## Hook (3 seconds)
**VISUAL**: Close-up of journal with morning routine, frustrated expression
**VOICEOVER**: "I was journaling every morning but still accomplishing nothing."

## Problem (8 seconds)
**VISUAL**: Screen recording - endless task list scrolling, 40+ items, all marked "important"
**VOICEOVER**: "As a startup founder, everything feels urgent. But 90% of my 'important' tasks were actually killing my business."

## Insight (8 seconds)
**VISUAL**: Split screen - LEFT: Revenue/Growth tasks (3 items), RIGHT: Everything else (37 items)
**TEXT OVERLAY**: "SIGNAL vs NOISE"
**VOICEOVER**: "Signal moves your business forward. Everything else is noise. That simple."

## Solution (10 seconds)
**VISUAL**: App interface - binary choice buttons, AI message popping up
**AI MESSAGE ON SCREEN**: "You said this was signal yesterday. Did you ship it?"
**VOICEOVER**: "So I built an app that forces this choice. Plus an AI that holds me accountable like a tough co-founder."

## Result (4 seconds)
**VISUAL**: Before/after comparison - 40 tasks → 8 tasks, completion checkmarks
**VOICEOVER**: "Result? I ship 3x more business-critical work."

## CTA (2 seconds)
**VISUAL**: Clean app interface with URL
**VOICEOVER**: "Built for founders, by a founder."
**TEXT**: "signal-noise.app"
