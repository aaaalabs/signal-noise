Identify what's maintenance, optimization, or transformation

Level 1: Maintenance
Keeps lights on
Daily operational work that maintains existing systems and processes. Necessary but creates no new value. Can consume 70-80% of your day if unmanaged.
Characteristics:
Anyone with basic training could complete this task
Task is repetitive and routine
Outcome is predictable and incremental
Required for operations but doesn't move goals forward
Can be batched, delegated, or automated
Examples:
→ Responding to routine emails
→ Attending standard status meetings
→ Filing reports or documentation
→ Data entry and admin tasks
→ Routine customer support

🎯 Task Categorization Decision Framework
Q1: Would completing this task alone make today successful?
If YES → Likely Level 3. If NO → Level 1 or 2.
Q2: Could someone else do this with a 5-minute briefing?
If YES → Level 1 (delegate it). If NO → Level 2 or 3.
Q3: Will this matter a month from now? A year from now?
If NO → Level 1. If MONTH → Level 2. If YEAR → Level 3.
Q4: Does this create new value or just maintain existing systems?
MAINTAIN → Level 1. IMPROVE → Level 2. CREATE NEW → Level 3.
Q5: What's the potential impact?
0-10% gain → Level 1-2. 10-50% gain → Level 2. 2-10× impact → Level 3.
